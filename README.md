## 📖 About
這是我的個人經歷、設計作品與開發專案的互動式網站。


##  Tech Stack
- **Core:** React 19, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v3 

##  Key Features
- **Custom Cursor:** 針對桌面版設計的互動式游標。
- **Interactive Typography:** 滑鼠互動標題與動態跑馬燈效果。
- **Responsive Design:** 完美支援桌機與行動裝置的自適應排版。
